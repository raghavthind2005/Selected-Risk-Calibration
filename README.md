# Selected-Risk Calibration

Code and stored results for *Selected Risk Calibration For Feasibility at
Returned Decisions*.

When an optimization problem uses a surrogate constraint, a decision that is
feasible for the surrogate need not be feasible for the true constraint.
Selected-risk calibration (SRC) calibrates a learned constraint against the
decisions the optimizer returns, for objectives drawn from a given
distribution, and certifies the result with a finite-sample, distribution-free
bound.

Repository: <https://github.com/raghavthind2005/Selected-Risk-Calibration>

## Install and run

    python3 -m venv .venv
    source .venv/bin/activate            # Windows: .venv\Scripts\activate
    pip install -r requirements.txt
    ./run_all.sh

`run_all.sh` rebuilds every table and figure from `results/`. It honours `PYTHON` if you would rather point at a specific interpreter,
and warns when no virtual environment is active.

`REPRODUCE.md` gives the two levels — rebuilding the outputs from stored
results, and rerunning a study from scratch — with measured runtimes.

The three studies in the paper:

- **Coverage diagnostic.** A margin that covers random inputs at its nominal
  rate need not cover the decisions an optimizer returns. On these benchmarks a
  margin covering about 90% of random inputs covered as few as 17% of the
  returned decisions.
- **Certification study.** SRC sizes five candidate shapes to a target cost,
  selects one, and certifies it. None of the 22 certified margins had a fresh
  violation rate above the target of 0.12; the highest was 0.050.
- **Matched-cost comparison.** Held to the same deployment cost, SRC's
  correction had fewer violations than the baseline in 57 of 62 comparisons,
  and significantly fewer in 53 (exact McNemar test, p < 0.05).

## Layout

    src/ocl/           the method: conformal margin, candidate family,
                       the correction, the certification test, and the
                       multistart solver
    src/matched_cost/  the matched-cost pipeline and its analysis helpers
    benchmarks/        the methane reactor, Williams-Otto plant and Hanoi
                       network simulators, and their data
    experiments/       entry point and configuration for each study
    results/           the stored results every table and figure is built from
    analysis/          results -> derived CSVs -> tables and figures
    config/            reported_arms.json, the one place the comparison set is set
    derived/           CSVs written by analysis/ (regenerated by run_all.sh)
    tables/ figures/   the committed outputs
    smoke/             fast checks
    MANIFEST.sha256    a hash for every file

### Certifying a margin

`src/ocl/certify.py` is the certification test: the one-sided Clopper-Pearson
bound, the largest violation count that still certifies, and the final step that
returns the cheapest certified margin or abstains. It reads gamma, delta, K and
n from `config/reported_arms.json`.
`experiments/certification/run_certification.py` is a standalone implementation
of the procedure used in the study, checked against the stored results: it
certifies one locked margin end to end on a benchmark.
`smoke/certify_check.py` recomputes all 40 margins of the study from their
stored violation counts and compares them with `tables/tab_cert_all.tex`.
